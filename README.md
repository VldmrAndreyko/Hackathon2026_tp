# Автоматизированная система обработки корпоративной почты

Небольшое приложение, которое само разбирает входящую почту: читает письма из папки, понимает, что это за письмо, и раскладывает его по нужным папкам. В конце показывает короткий отчёт — сколько писем прочитано и что куда попало.

Задача пришла из реальной боли: отдел поддержки получает сотни писем в день, и важные обращения легко теряются среди рекламы и рутины. Эта система берёт сортировку на себя.

## Что делает программа

1. Читает все письма из папки `inbox/`.
2. Для каждого письма определяет категорию.
3. Перемещает письмо в соответствующую папку внутри `sorted_inbox/`.
4. Печатает итоговую статистику.

## Как письма распределяются по папкам

| Папка             | Что туда попадает                                                                                                            |
|-------------------|------------------------------------------------------------------------------------------------------------------------------|
| `spam`            | Реклама, розыгрыши, «выгодные предложения». Ловим по ключевым словам: *выиграть, скидка, приз, акция, казино, ссылки* и т.п. |
| `urgent`          | Срочные обращения и инциденты: *срочно, авария, ошибка, взлом, вирус, недоступен* и т.п.                                     |
| `non_urgent`      | Всё остальное, что нормально прочиталось, но не похоже ни на спам, ни на срочное. Это «папка по умолчанию».                  |
| `non_classified`  | Письма, которые не получилось прочитать: пустые, повреждённые или в неизвестном формате (не `.txt`).                         |
| `/no-attachments` | Вложенная папка в папки urgent и non_urgent, в которую входят письма без вложений.                                           |
| `/attachments`    | Вложенна папка в папки urgent и non_urgent, в которую входят письма с вложениями.                                            |


При проверке ключевых слов используется морфологический анализ (библиотека `pymorphy3`). Это значит, что слова распознаются в любой форме — например, «ошибка», «ошибки» и «ошибкой» считаются одним и тем же словом. Так классификация работает заметно надёжнее, чем простое сравнение строк.

### Что будет с письмом, которое «не подошло»

Это специально продуманный момент. Система устроена так, чтобы **ничего не терялось**:

- Если письмо прочиталось, но не похоже ни на спам, ни на срочное — оно отправляется в `non_urgent`. То есть появление нового, незнакомого типа письма не ломает систему: оно просто попадёт в общую папку, а не пропадёт.
- Если письмо вообще не удалось прочитать (пустой файл, картинка, битый формат) — оно уходит в `non_classified`, и приложение продолжает работать дальше, не падая.

Добавить новую категорию легко: ключевые слова собраны в одном месте — в файле `KeyWords.py`.

## Структура проекта

```
.
├── main.py              # точка входа: запускает весь процесс
├── FileReader.py        # читает письма из папки, считает прочитанные/непрочитанные
├── FileManager.py       # создаёт папки категорий и перемещает в них письма
├── EmailClassifier.py   # определяет категорию письма (спам / срочное / прочее)
├── Email.py             # модель письма и разбор его полей (от кого, тема, текст…)
├── KeyWords.py          # словари ключевых слов для классификации
├── EmailLogger.py       # ведение журнала событий обработки
├── inbox/               # входящие письма (исходные данные)
├── run.sh               # скрипт запуска
├── requirements.txt     # зависимости
└── README.md
```

Папка `sorted_inbox/` с подпапками категорий создаётся автоматически при первом запуске.

## Что нужно для запуска

- Python 3.8 или новее
- Библиотека `pymorphy3` (ставится одной командой, см. ниже)
- А также библиотеки из requirements.txt

## Как запустить

Самый простой способ — через готовый скрипт:

```bash
./run.sh
```

Скрипт сам проверит окружение, при необходимости доустановит зависимость, запустит обработку и сохранит весь вывод в файл `run.log`. Если что-то пойдёт не так (нет папки `inbox/`, не установлен Python) — он понятно об этом сообщит.

Если скрипт не запускается, сначала дайте ему права на выполнение:

```bash
chmod +x run.sh
```

Можно запустить и вручную, без скрипта:

```bash
pip install -r requirements.txt   # один раз
python3 main.py
```

## Что вы увидите на выходе

В консоли появится примерно такой отчёт:

```
Итоговая статистика:
Успешно прочитано: 104 файлов
Не удалось прочитать: 5 файлов, они отправлены в папку 'non_classified'
В папке spam: 6 файлов
В папке urgent/no-attachments: 7 файлов
В папке urgent/attachments: 13 файлов
В папке non_urgent/attachments: 48 файлов
В папке non_urgent/no-attachments: 30 файлов
В папке non_classified: 5 файлов

```

А рядом появится папка `sorted_inbox/` с разложенными по категориям письмами.

## Важно: письма перемещаются, а не копируются

После запуска папка `inbox/` опустеет — письма физически переезжают в `sorted_inbox/`. Это нормально. Но если захотите прогнать обработку ещё раз, сначала верните письма обратно в `inbox/` — проще всего заново клонировать репозиторий или восстановить папку из системы контроля версий.
